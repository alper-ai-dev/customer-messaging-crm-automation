# Relay — Customer Messaging & CRM Automation

A credential-free portfolio demo for customer-message triage and CRM-style follow-up routing.

## Features
- Multi-channel inbox simulation
- Deterministic message classification
- Billing, sales, technical and general-support routing
- Priority and sentiment signals
- Response-target assignment
- Next-best-action rules
- CRM-style follow-up queue
- Responsive operations interface

## How it works
Inbound messages are evaluated locally using transparent rules and intent signals. The application assigns a category, urgency, route, recommended action and response target. A user can then create a follow-up task in the CRM-style queue.

## Scope
This public demo does not claim a live WhatsApp, Messenger, email or CRM integration. Channels are simulated so the project can be tested without private credentials. In production, the same routing layer can sit behind approved messaging APIs, webhooks and a CRM.

## Stack
HTML5, CSS3, Vanilla JavaScript.
